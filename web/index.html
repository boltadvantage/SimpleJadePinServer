Jade PIN Server

Offline

A self-hosted blind PIN oracle for the Blockstream Jade. Everything runs on this machine — no network calls leave it.

→ Keys & backup

1

Point your Jade at this server

One time only

Skip this if your Jade already uses this server — go straight to Step 2.

Only do this on an uninitialized Jade. Setting a new blind oracle on a Jade that is already set up requires a factory reset, which erases the wallet. Moving an existing Jade to this machine? Restore your keys instead — see Keys & backup.

On the Jade:

  1. Power the Jade on.
  2. As the logo appears, press both buttons at once — a short press, do not hold. This opens the boot menu. On some models and firmware a single click of the select button opens the same menu. If both-buttons does nothing, power off and try one click as the logo shows.
  3. Select Blind Oracle.
  4. Select Scan Oracle QR.
  5. Open the page below, generate the code, and scan it with the Jade.
  6. Confirm the details shown on the Jade’s screen.
