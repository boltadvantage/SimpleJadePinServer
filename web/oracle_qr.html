Getting to the setting on your Jade

  1. Power the Jade on.
  2. As the logo appears, press both buttons at once — a short press, do not hold. This opens the boot menu. On some models and firmware a single click of the select button opens the same menu. If both-buttons does nothing, power off and try one click as the logo shows.
  3. Select Blind Oracle.
  4. Select Scan Oracle QR.
  5. Generate the code below and scan it with the Jade.
  6. Confirm the details shown on the Jade’s screen.
The Jade must be uninitialized to set a new blind oracle. If your Jade is already set up, applying a new oracle requires a factory reset, which erases the wallet. You will need your recovery phrase to restore it. If you are moving an existing setup to this machine, do not re-scan this code — copy your existing keys across instead (see Keys & backup).

Server details

If you only ever use the Jade in QR mode, the URL does not matter. The public key is the only field the Jade relies on. The URL must be correct and reachable only for firmware upgrades over USB or Bluetooth.
